# Cisco-Packet-Tracer-Network-Labs
A collection of hands-on network simulations built in Cisco Packet Tracer.

## Requirements

To open and interact with any of the `.pkt` files in this repo you will need:

- **Cisco Packet Tracer** — free to download via the [Cisco Networking Academy](https://www.netacad.com/cisco-packet-tracer) (free account required)
